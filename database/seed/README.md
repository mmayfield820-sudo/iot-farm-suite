# 当前数据快照

`001_demo_data.sql` 是从交付时正在运行的 MySQL 数据库取得的一致性快照，仅用于空库初始化。它保留当前主键、业务状态和演示记录，不承担历史数据库升级。

快照主要包含：

- 3 个演示账号及对应的农户、农场管理员、系统管理员角色；其中 `demo_admin` 保持待激活，便于测试激活登录。
- 2 个奉节橙园、4 个地块及农户/管理员数据范围。
- 5 套种植模板：1 套通用模板和 4 套品种 V1.1 全周期模板；P001～P004 已绑定各自品种模板。
- 10 台当前设备、4 份地块阈值配置，以及快照时已有的监测、MQTT、灌溉和告警记录。
- 当前计划变更申请、农事任务、操作审计和注册申请状态；空表也会保持为空。

该脚本包含密码哈希和激活令牌哈希等测试数据，只适合项目本地开发环境，不应直接用于生产环境。
