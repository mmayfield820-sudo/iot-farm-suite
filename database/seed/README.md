# 演示数据

`001_demo_data.sql` 是当前橙园产品的完整初始化数据，仅面向新建数据库执行，不再通过 `UPDATE` 或清理旧业务数据的方式进行版本兼容。

初始数据包含：

- 3 个演示账号：农户、农场管理员、系统管理员。
- 2 个橙园农场，同属一个农场管理员。
- 农户可访问的 4 个橙树地块。
- 与项目鸿蒙模拟器 UUID 一致的设备。
- 用于前端展示的阈值、墒情趋势、5 次已完成灌溉会话和 10 条告警。
- 1 套 `FJ_NAV_GENERIC` 奉节脐橙成年结果树通用管理模板，并将 4 个演示地块关联到该模板。
- 3 个演示账号均标记为 `ACTIVATED`，确保升级后原登录方式保持兼容。

初始化后所有灌溉设备的工作状态均为 `stopped`，不会在前端默认显示为灌溉中。

此文件只供空库初始化。已有一期数据必须先备份，再执行 `database/migrations` 中的阶段 1 脚本；不要用演示种子覆盖历史数据。
