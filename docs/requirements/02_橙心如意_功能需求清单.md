# 橙心如意：奉节脐橙全周期数字管理平台 - 二期功能需求清单

## 零、二期课题定义与约束

本节是二期需求的解释依据，优先级高于后续同名或相冲突的用户故事。

### 0.1 项目背景

橙心如意服务重庆市奉节县脐橙产区农业公司旗下的橙园。一个橙园在同一生产周期内种植同一脐橙品种，按统一基准进入生产、采收和清园；农户负责所辖地块的现场执行和记录，不独立决定地块品种、种植批次或生产计划规则。

### 0.2 关键术语

| 术语 | 定义 | 维护人 |
| --- | --- | --- |
| 基础资料 | 橙园、地块、员工、角色及授权范围等平台主数据；不包含生产周期信息。 | 系统管理员 |
| 标准模板 | 面向奉节脐橙的公司级可复用栽培规则，包含阶段、时长、管理重点、任务和墒情目标。 | 系统管理员 |
| 农场生产资料 | 某橙园当前周期采用的模板版本、定植基准、树龄、清园状态和下一周期开始日期。 | 农场管理员 |
| 农场周期版本 | 某橙园当前或下一生产周期实际采用的版本，是标准模板在本农场的版本化快照。 | 农场管理员 |
| 草稿 | 下一周期尚未发布的农场周期版本，可在维护窗口内修改。 | 农场管理员 |
| 计划 | 按农场生产资料和已发布农场周期版本，为每个有效地块生成的任务快照。 | 农场管理员生成，农户执行 |

### 0.3 角色职责边界

| 角色 | 职责边界 | 明确不承担的职责 |
| --- | --- | --- |
| 系统管理员 | 维护基础资料；预置账号及授权范围；维护公司级标准模板库。 | 不依据现场情况直接修改某农场的生产周期或计划。 |
| 农场管理员 | 在获授权橙园内维护农场生产资料；生成、修改和发布下一周期草稿；生成或重新生成地块计划；查看生产和设备运行。 | 不维护橙园、地块、员工、角色或授权范围；不修改公司级标准模板。 |
| 农户 | 仅执行获授权地块的任务；调整本人未完成任务的日期、备注和状态；提交完成记录与计划外农事。 | 不修改模板、农场生产资料、农场周期版本或计划生成规则。 |

### 0.4 账号与授权规则

1. 账号由系统管理员通过 Excel 或账号管理预置，不提供公开注册。
2. 员工以工号登录；身份证号后六位为初始密码。首次使用初始密码登录即视为激活，员工须设置正式密码并补充联系方式。
3. 身份证号明文不入库，仅保存不可逆摘要和脱敏展示值。
4. 农场管理员仅能访问获授权橙园；农户仅能访问获授权地块及其关联设备和任务。

### 0.5 周期、模板与计划规则

1. 系统优先匹配“脐橙 + 重庆市奉节县”的标准模板，其次为通用脐橙、通用柑橘模板；无可用模板时由系统管理员维护标准模板。
2. 标准模板的已发布版本保留为历史版本，不直接改写。农场管理员只能基于本农场当前版本创建下一周期草稿。
3. 草稿仅在“采收后清园已完成”至“下一周期开始日期之前”的维护窗口内可修改和发布。发布后形成新的农场周期版本。
4. 计划是地块任务快照。重新生成计划会以新计划替代原活动计划，并保留原计划的历史状态；农户不可改写计划规则。
5. 农户可根据现场情况调整自己的未完成任务日期、备注和状态，并完成任务或补记计划外农事；所有调整和完成结果应留存记录。

## 一、项目定位

橙心如意面向重庆市奉节县脐橙产区农业公司旗下橙园的内部管理辅助平台，服务农场管理员和地块负责人开展种植计划、环境监测、灌溉处置与农事记录工作。

平台账号、橙园和地块均采用“系统管理员预置、员工使用”的管理模式：系统管理员通过 Excel 批量导入创建员工账号、角色和授权范围，并维护橙园及地块基础档案；员工完成身份验证后设置登录凭证。农场管理员不得新建、修改或删除橙园、地块，也不得修改用户角色和地块授权范围。

核心业务闭环：

`系统管理员建立橙园/地块并导入人员授权 -> 员工激活账号 -> 农户登记种植信息 -> 系统按品种模板生成管理计划 -> 农户完成待办 -> 监测数据触发灌溉建议和调整提醒 -> 农户确认执行 -> 留存记录`

## 二、用户角色

| 角色 | 职责 | 核心权限 |
| --- | --- | --- |
| 农场管理员 | 维护所辖橙园的生产周期并协调日常管理 | 维护农场生产资料、维护和发布下一周期版本、生成计划、查看生产与设备状态、绑定或解绑已登记设备 |
| 农户 | 负责被授权地块的农事执行和记录 | 查看和调整本人未完成任务、完成农事待办、补记计划外农事、查看数据、控制授权灌溉设备 |
| 系统管理员 | 维护基础资料、人员账号、权限和标准模板库 | 维护橙园与地块、批量导入用户并分配授权范围、维护公司级品种模板、查看系统日志 |
