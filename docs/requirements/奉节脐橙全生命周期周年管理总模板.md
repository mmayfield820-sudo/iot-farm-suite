# 奉节脐橙全生命周期周年管理总模板（V1.0）

> 本模板为"橙心如意"平台**单一主模板**，覆盖定植第1年至盛果期。系统依据地块的**定植日期**自动计算树龄，按以下规则分流：
> - **定植1-3年** → 执行"幼树轨道"（以长树扩冠为核心）
> - **定植4年及以上** → 执行"结果树轨道"（以产量品质为核心）

---

## 三、各阶段管理任务总表（双轨并行）

### S1 休眠期（清园越冬）｜12月—次年1月

| 任务 | 幼树轨道（1-3年） | 结果树轨道（4年+） |
|------|------------------|-------------------|
| 修剪 | 轻剪整形，剪除病虫枝、弱枝 | 重剪回缩，清除枯枝、密枝、下垂枝 |
| 冬肥 | 每株尿素0.1kg+普钙0.1kg+硫酸钾0.1kg+粪肥5kg | 每株有机肥5-7.5kg+复合肥0.5kg |
| 清园 | 清除落叶杂草，喷洒石硫合剂 | 喷洒石硫合剂，消灭越冬虫卵 |
| 防冻 | 树干涂白+树盘覆盖稻草 | 树干涂白+叶面喷施有机营养液 |
| 墒情目标 | 55%—65% | 55%—65% |

| 任务 | 幼树轨道（1-3年） | 结果树轨道（4年+） |

| 追肥 | 3月浇清粪水 | 叶面喷施硼肥，增强花质 |
| 修剪 | 春季轻剪，培养主枝骨架 | 春季简化修剪 |
| 花果管理 | **全部疏除花蕾**（避免消耗营养） | 保花保果，提高坐果率 |
| 病虫防治 | 防治蚜虫、红蜘蛛 | 防治红蜘蛛、蚜虫、疮痂病 |
| 墒情目标 | 60%—70% | 60%—70% |

## 六、模板在平台中的自动分流逻辑

> 这是本模板在"橙心如意"系统中的**核心运行规则**

```
输入：地块定植日期（农户登记时录入）
计算：树龄 = 当前年份 - 定植年份

IF 树龄 ≤ 3年:
    执行「幼树轨道」（每阶段左列任务）
    核心标识：★ 全部抹花抹果 ★ 勤施薄施 ★ 抗旱保苗
    系统不生成「保花保果」「疏果」「采收」类任务

IF 树龄 ≥ 4年:
    执行「结果树轨道」（每阶段右列任务）
    核心标识：★ 保花保果 ★ 控夏梢 ★ 壮果增甜
    系统正常生成「花期管理」「疏果」「采收」等完整任务链
```

**特殊情况**：定植第3年秋季，系统可推送提示"建议明年起过渡为结果树管理"，由农场管理员在生成下一周期草稿时手动确认是否切换轨道。

## 七、模板使用说明（给农场管理员）

1. **新建地块时必填"定植日期"**，系统据此自动计算树龄并分流任务，这是本模板生效的前提
2. 同一橙园内若有不同年份定植的地块，系统会为每个地块独立计算轨道，互不影响
3. 幼树轨道不生成花果管理和采收类任务，避免农户收到无效待办
4. 4-5年初结果树如树势较弱，农场管理员可在下一周期草稿中手动"暂缓切换"，延用幼树轨道一年
5. 肥料用量为单株参考值，实际执行中应结合树势、土壤条件微调；严禁使用氯化钾型肥料
