智慧农业平台 · Windows 一键启动包
====================================

一、这是什么
    一个"下载解压后双击就能用"的平台包。含全套 5 个服务
    （数据库 / MQTT 消息中间件 / 后端 / AI 问答 / 网页前端），
    不需要联网下载任何东西，不需要敲任何命令。

二、准备（只做一次，约 10 分钟）
    1. 电脑系统：Windows 10 或 11（64 位）
    2. 安装 Docker Desktop：
        下载地址：https://www.docker.com/products/docker-desktop/
        安装后双击打开它，等底部变成绿色 "Engine running"。
       （若电脑里没有网卡/虚拟化被禁用，装不上时，请改用云服务器方案，
        见《部署文档.md》第 6 节。）

三、使用（以后每次就这么做）
    1. 双击  「启动.bat」
    2. 第一次运行会自动加载镜像（3~5 分钟），之后每次都是秒开
    3. 浏览器自动打开 http://localhost ，用演示账号登录：

           账号          密码
        管理员  demo_admin      DemoPass123!
        农户    demo_farmer     DemoPass123!
        系统    demo_system     DemoPass123!

    登录成功 = 一切正常。

四、停止 / 数据
    停止平台：双击「停止.bat」
    平台停止后数据都保存在 Docker 里，下次「启动.bat」数据还在。

五、AI 问答功能（可选）
    平台所有功能默认全可用，只有"AI 农业问答"需要填 API Key：
      1. 用记事本打开  iot-farm-suite\.env
      2. 找到这两行填上（向团队负责人索取）：
            AI_MODEL_API_KEY=sk-你的硅基流动key
            BOCHA_API_KEY=sk-你的博查key
      3. 保存后双击「停止.bat」再双击「启动.bat」即可
    不填也能用平台其他全部功能，AI 问答会提示"服务不可用"，属正常。

六、常见问题
    Q1 双击启动.bat 报"Docker 未就绪"
       → 没装 Docker Desktop，或装完没打开。按上面"准备"第 2 步做。

    Q2 报"端口被占用" / bind: address already in use
       → 电脑里已有程序占用了 80（网页）或 1883（MQTT）端口。
         一般是 IIS、Nginx、Apache 或之前装过的 MQTT 软件。
         处理：打开「停止.bat」所在的命令行里执行
              netstat -ano | findstr ":80"
         找到占用进程 PID，在任务管理器结束它；或换端口。
         也可以改用云服务器方案（见部署文档）。

    Q3 浏览器打开了但提示连不上
       → 平台还在初始化（首次启动数据库要建数据，约 1 分钟）。
         等一会儿手动刷新 http://localhost 即可。

    Q4 演示账号登录不上
       → 确认密码是 DemoPass123!（区分大小写）。

    Q5 想给老师/同学演示但不想用自己电脑
       → 团队已部署云演示环境，浏览器直接访问（见《部署文档.md》）。
